# Web App

The web app will provide the Imaginarium Command Center interface.

## Initial Views

- New workflow request
- Active workflow runs
- Transcript and intelligence review
- Clip candidate review
- Export and approval screen

## First User Journey

1. Paste a YouTube URL.
2. Add an optional audience or business goal.
3. Start the workflow.
4. Monitor processing status.
5. Review transcript, insights, and clip candidates.
6. Approve selected outputs for export.
